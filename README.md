Automated Cloud ETL Pipeline using Python, PostgreSQL & Snowflake

An end-to-end ETL (Extract, Transform, Load) pipeline built using Python, Pandas, PostgreSQL, and Snowflake.
The project automates data extraction, cleaning, transformation, validation, and loading into databases with incremental loading and scheduler automation.

🚀 Features
Automated ETL workflow
CSV-based data ingestion
Data cleaning & transformation using Pandas
Incremental loading (only new records inserted)
Duplicate prevention using primary key validation
PostgreSQL integration
Snowflake cloud warehouse integration
Automated scheduler using APScheduler
Report generation
Logging & error handling
Modular project architecture
